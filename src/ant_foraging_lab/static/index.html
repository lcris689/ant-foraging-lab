Variable guide

Directional effects are typical, not guaranteed. Every run is stochastic.

Seed
Replays one random sequence. Changing it changes individual paths and outcomes, not the intended scenario.
Ants
Colony size (1–500). More ants usually increase encounters and deliveries, but also increase compute.
Grid size
Width and height (20–150 cells). Larger grids usually make exact feeder discovery slower and sparser.
Max steps
Absolute run horizon (1–5,000). More steps allow more discovery and transport but use more compute.
Sample every
Steps between recorded frames (1–250). Smaller values make smoother replays and larger downloads without changing model outcomes.
Stop rule
Ends at a fixed horizon, first empty feeder, or all empty feeders. Changing it changes when results are observed.
Nest X / Y
Home and starting coordinates. Moving the nest changes travel distances to every feeder.
Feeder X / Y
Resource coordinates. Feeders nearer the nest are usually found and serviced sooner.
Quality
Probability (0–1) that an uncommitted ant commits after reaching that feeder. Higher values make accepted discoveries more likely.
Food
Starting inventory. More food keeps a feeder available longer but does not make it easier to find.
Recruitment
Probability (0–1) for one eligible nest-based recruitment attempt. Higher values usually spread an established commitment faster.
Attrition
Per-step probability (0–1) that a committed ant becomes uncommitted. Higher values make allocations less persistent.
